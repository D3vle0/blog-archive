# My first hugo website


![hugo](/hugo-logo.png)

2017년 부터 아래의 개인 블로그 변천사를 거치고, static site generator인 hugo를 이용해 블로그를 운영하게 되었다.

- 2017년 [네이버 블로그](http://devleoblog.kro.kr)
- 2019년 [티스토리](https://devleo.tistory.com)
- 2021년 [oopy.io](oopy.io)
- 2021년 hugo

터미널에서 글을 쓸 수 있고 블로그 글을 쓰는 절차가 코딩과 비슷하여 hugo를 선택해 보았다. 노션에 기록해 둔 자료들, 앞으로 연구 및 개발할 내용들을 하나씩 적어나갈 것이고, public 한 personal 메모장 느낌으로 운영할 생각이다. 개발하면서 특정 에러를 고친 방법, 현재 연구중인 android forensics 관련 자료, tech news 등의 자료들이 준비중에 있다.
