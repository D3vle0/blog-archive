# Android Forensics


## 서론

교내 자율동아리 UNTRUST 에서 2학기 첫 수업을 진행하게 되었다.
웹플과이기에 너무 보안적인 내용에 집중하기 보다는 상대적으로 쉬운 포렌식 분야와 개발과 연관된 내용을 발표하면 좋을 것 같아서 안드로이드 포렌식에 대해 발표하게 되었다.

## 목차

1. 안드로이드의 역사
2. 설치
3. 안드로이드를 루팅하는 여러가지 방법
4. 잠금 화면을 무력화시키는 방법
5. 패턴과 비밀번호 알아내기
6. 왜 오래된 안드로이드를 사용하는가?
7. 문제풀이
