First post in my new blog

I used to manage my blog since last July using hugo static site generator.
But after recovering my Macbook Air through DFU mode, I had to lost all of my data include my projects, some system tweaks and even original hugo blog data.

My original hugo theme was “LoveIt” and it has a lot of features for developer such as line number in code block, content shortcut buttons, and perfect shortcodes. But I don’t like its color scheme and the most important thing is - the space between the lines is too narrow.

So I decided to change theme through this chance. A good theme for developer needs:

  1. Dark mode
  2. Code block with monospaced font and syntax-highlighting
  3. Tag feature
  4. Minimalistic

This “Paper” theme is the right theme that I needed.
